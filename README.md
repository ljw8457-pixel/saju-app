# 사주 한 장 — 지인 테스트용 사주 웹앱

모바일에서 바로 열리는 단일 HTML 사주 앱입니다. 외부 API·키·인터넷 연결 없이 파일 하나로 동작합니다.

## 열기 / 공유

- 폰이나 PC에서 `index.html`을 열면 바로 실행됩니다. (안드로이드 크롬, iOS 사파리, PC 브라우저)
- 링크로 지인에게 보내려면 GitHub Pages 같은 정적 호스팅에 올리면 됩니다.
  - 예: 저장소에 `index.html`을 올리고 Settings → Pages → Branch: main / root 선택 → `https://<계정>.github.io/<저장소>/`
- 카카오톡으로 파일 자체를 보낼 때는 zip으로 묶어 보내고, 받은 사람이 브라우저로 열면 됩니다.

### 지인 초대 전용 링크(입장 코드 잠금)

- 기본 주소(`https://ljw8457-pixel.github.io/saju-app/`)로 접속하면 잠금 화면만 보이고 사주 앱 본문은 열리지 않습니다.
- 공유할 때는 전용 링크를 보냅니다: `https://ljw8457-pixel.github.io/saju-app/?k=saju26`
- 전용 링크로 열거나 잠금 화면에 입장 코드 `saju26`을 입력하면 해제되고, 같은 기기에서는 새로고침해도 유지됩니다(localStorage).
- 검색엔진 노출 차단: `<meta name="robots" content="noindex, nofollow">` + `robots.txt`(`Disallow: /`).
- 이 잠금은 링크를 아는 사람만 들이는 가벼운 초대용 장치입니다. 페이지 소스에는 코드가 들어 있으므로, 소스를 열어 보는 사람에게는 보호되지 않습니다.

## 배포 구조

- GitHub Pages 주소: <https://ljw8457-pixel.github.io/saju-app/>
- Pages 배포 소스는 `gh-pages` 브랜치(`/`)입니다. (GitHub App 권한 한도로 main을 소스로 지정하는 API 변경이 안 되어, `gh-pages` 브랜치를 만들었을 때 GitHub이 자동으로 Pages를 켰습니다.)
- 따라서 내용을 고칠 때는 `main`에 커밋한 뒤 **`main`을 `gh-pages`로도 푸시**해야 사이트에 반영됩니다.
  - `git push origin main`
  - `git push origin main:gh-pages`
- 저장소 설정에서 직접 바꾸려면 <https://github.com/ljw8457-pixel/saju-app/settings/pages> 에서 Branch를 `main` / `/ (root)`로 바꿔도 됩니다. 그렇게 바꾸면 `gh-pages` 브랜치는 지워도 됩니다.

## 입력 항목

| 항목 | 설명 |
| --- | --- |
| 이름 | 선택. 결과 제목과 요약에만 쓰입니다. |
| 성별 | 대운 순행/역행 계산에 사용합니다. |
| 달력 | 양력 / 음력(평달·윤달). 음력은 한국천문연구원 음양력 데이터를 씁니다. |
| 생년월일 | 1930~2030년. 음력은 그 해에 실제 있는 윤달만 체크할 수 있습니다. |
| 시간 | 시·분 직접 입력, 12시진 버튼, ‘시간 모름’(시주 없이 3주 계산) 지원. |
| 서울 경도 보정 (−30분) | 기본 켜짐. 동경 135° 표준시와 서울(약 127°)의 차이를 시주·일주에 반영합니다. |
| 서머타임 자동 보정 | 기본 켜짐. 1948~1960·1987~1988년 여름의 시계 시각에서 1시간을 되돌립니다. |
| 23시 이후 다음 날(조자시) | 기본 꺼짐(자정 기준, 야자시). 켜면 23시 이후 출생을 다음 날 일주로 봅니다. |

## 풀이 구성

결과 화면의 풀이는 아래 8개 섹션으로 나옵니다. 만세력 계산값(일간·십성·오행·강약·지지 관계)을 조합해 규칙 기반으로 문장을 만듭니다.

| 섹션 | 내용 |
| --- | --- |
| 01 타고난 성격과 기질 | 일간의 기본 기질 + 가장 두드러진 십성 + 오행 과다·부족 + 신강·중약·신약 + 원국의 합·충·형 |
| 02 말투와 일하는 방식, 지칠 때의 나 | 말투, 일 처리 방식, 속마음, 스트레스 푸는 방식 |
| 03 직업과 재물의 흐름 | 일간·십성 조합에 따른 직업 적성과 재물 흐름, 강약별 조언 |
| 04 연애와 대인관계 | 일지(배우자 자리) 기반의 애정 표현 방식과 관계 패턴 |
| 05 잘 맞는 사람, 피곤해지는 사람 | 부족한 오행을 채워 주는 사람, 생·극 관계별 사람 유형, 일지 기준 띠 궁합 |
| 06 2026년 병오년 | 천간 십성 + 지지와 일지의 관계 + 상·하반기 흐름 |
| 07 2027년 정미년 | 2027년 기운의 변화, 올해와의 차이, 챙길 점 |
| 08 채우면 좋은 오행과 습관 | 보완 오행의 색·장소·습관·음식 |

- 각 섹션은 3~7단락으로, 비유와 생활 예시를 섞어 읽는 재미를 살렸습니다.
- ‘결과 요약 복사’는 키워드·2026·2027 한 줄 요약·잘 맞는 사람까지 함께 복사합니다.

## 계산 기준

- **음양력**: 한국천문연구원(KASI) 음양력 데이터를 1930~2030년 범위로 내장 (`lunar-data.js` → index.html에 인라인). 중국 음력과 다른 해가 있어 중국 라이브러리 표를 쓰지 않았습니다.
- **24절기**: `lunar-javascript 1.7.7`의 천문 계산값을 사용하되, 라이브러리 값이 중국 표준시(UTC+8) 기준이므로 +1시간 해 한국 표준시로 맞춰 비교합니다.
  - 연주는 입춘 절입 시각, 월주는 12절(節) 절입 시각 기준입니다.
- **시주·일주**: 서울 지방평균시(−30분) 보정값의 시각으로 계산하고, 일주는 기본 자정(00시)에 바뀝니다.
- **표준시**: 1954-03-21~1961-08-09은 UTC+8:30, 그 외는 UTC+9. 서머타임은 IANA Asia/Seoul 이력(12개 해)을 따릅니다.
- **대운**: 3일=1년 전통 방식으로 절입까지의 시간을 환산하고, 양남·음녀는 순행, 음남·양녀는 역행입니다.

## 검증

`verify.py`가 `index.html`에 인라인된 코드를 그대로 꺼내 검사합니다.

```
pip install quickjs korean_lunar_calendar
python verify.py
```

검사 결과 (`verify-output.txt`) — 21개 검사 전부 통과

- 음력 ↔ 양력 변환 36,890일(1930-01-01~2030-12-31) 전수: KASI 데이터 라이브러리와 불일치 0건
- 일진(60갑자) 36,890일 전수: 불일치 0건
- 입춘 절입 시각 1946~2023년 78개년: 역서 공표값과 최대 2분 차이 (1954~61년은 당시 표준시가 UTC+8:30이라 표와 29~30분 차이가 정상)
- 절입 전후 전환: 1992-02-04 22:45 → 辛未년 辛丑월 / 22:50 → 壬申년 壬寅월
- 1992-02-03(입춘 전) · 1992-02-05(입춘 후) · 2000-01-01 · 음력 윤달(2023 윤2월) · 음력 1990.3.5 · 서머타임 on/off · 자시 옵션 · 시간 모름 · 대운 순행/역행

교차 확인한 외부 자료

- 입춘 절입 시각 1946~2023: 역서 기반 정리표 (bebeyam.com)
- 1992년 24절기·일진·음력: manseryeok.kr/1992, jaldoel.com 절기표, saju.taif.kr
  - 1992-02-04 입춘 22:48(KST), 1992-05-15 = 辛卯일 · 음력 1992.4.13
- 2000년 만세력(manseryeok.kr/2000): 2000-01-01 = 戊午일, 소한 2000-01-06 10:01, 입춘 2000-02-04 21:40
  - 앱의 ‘계산 기준’에도 절기 시각을 분 단위로 반올림해 같은 값(입춘 21:40 등)으로 표시합니다.

## 참고

- 해석은 규칙 기반으로 생성되는 재미용 텍스트입니다. 전문 역학 상담을 대체하지 않습니다.
- 출생 시각이 절입 시각과 1~2분 차이로 겹치면, 절기 계산값이 공표값과 1분 안팎 다를 수 있어 결과가 달라질 수 있습니다.
- 1954~1961년 출생자는 당시 표준시(UTC+8:30)와 서머타임이 겹쳐 실제 태양시와 최대 1시간 30분 차이가 날 수 있습니다. 두 옵션을 켜 두면 자동 반영됩니다.
- 진태양시(경도) 보정은 학파에 따라 적용 범위가 다릅니다. 이 앱은 시주·일주 경계에 적용하고, 절기 경계는 실제 순간으로 판정합니다.
